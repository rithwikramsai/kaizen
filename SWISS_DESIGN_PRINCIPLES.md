## 📐 **CORE SWISS DESIGN PRINCIPLES**

### **1. GRID-BASED LAYOUT**
```
Everything aligns to an invisible grid
- 8px or 4px base unit
- Consistent spacing
- Mathematical precision
- Visual rhythm
```

**For ACG:**
- ✅ Use 8px spacing system everywhere
- ✅ Align all elements to grid
- ✅ Consistent margins/padding
- ✅ No random spacing

---

### **2. TYPOGRAPHY AS PRIMARY DESIGN ELEMENT**
```
Type does the heavy lifting
- Clear hierarchy
- Generous whitespace
- Limited font weights (2-3 max)
- Readable sizes
```

**For ACG:**
- ✅ Helvetica/Inter (Swiss typefaces)
- ✅ Scale: 12, 14, 16, 20, 24, 32, 48px
- ✅ Weights: 400 (normal), 600 (semibold) only
- ✅ High contrast (black on white)

---

### **3. ASYMMETRIC LAYOUTS**
```
Not centered, not symmetrical
- Left-aligned text blocks
- Intentional white space
- Dynamic tension
- Functional asymmetry
```

**For ACG:**
- ⚠️ **EXCEPTION:** Login can be centered (it's a form)
- ✅ Dashboard: asymmetric grid
- ✅ Lists: left-aligned
- ✅ Details: content left, actions right

---

### **4. LIMITED COLOR PALETTE**
```
1-2 colors + black/white/gray
- Color for function, not decoration
- Red = action/emphasis ONLY
- Neutrals dominant
```

**For ACG:**
- ✅ ACG Red (#e8294a) = primary actions only
- ✅ Black (#171717) = text
- ✅ Gray scale = structure
- ✅ Status colors = semantic only

---

### **5. OBJECTIVE PHOTOGRAPHY / NO DECORATION**
```
Real content, no stock photos
- Functional imagery only
- No decorative illustrations
- Data visualization over decoration
```

**For ACG:**
- ✅ Remove all decorative elements
- ✅ Use real data in charts
- ✅ No floating particles/effects
- ✅ Icons = functional only

---

### **6. CLEANLINESS & PRECISION**
```
Every element has purpose
- No ornamentation
- Exact alignment
- Mathematical relationships
- Breathing room
```

**For ACG:**
- ✅ 1px borders (precise)
- ✅ Exact spacing (8px, 16px, 24px)
- ✅ Subtle shadows (functional depth)
- ✅ Clean edges

---

### **7. FUNCTIONAL HIERARCHY**
```
Visual weight = importance
- Size
- Weight
- Position
- Color
```

**For ACG:**
- ✅ Primary action = red, larger
- ✅ Secondary = outline
- ✅ Tertiary = gray
- ✅ Clear visual order

### **Enhancement 2: REFINED TYPOGRAPHY**
```
Current: Good hierarchy
Swiss: Perfect scale + spacing

Changes:
- Heading: 32px (4 × 8), 700 weight, -0.02em tracking
- Subhead: 16px (2 × 8), 400 weight

- Helper: 12px, 400 weight

### **Enhancement 3: PRECISE BORDERS & SPACING**
```
Current: 1px borders, good
Swiss: Consistent application

Changes:
- All borders: 1px solid #e5e5e5
- No doubled borders (card + input)
- Consistent border radius: 8px
- Input focus: 2px ring (not 3px)
```

### **Enhancement 4: COLOR DISCIPLINE**
```
Current: ACG red used well
Swiss: Even more restrained

Changes:
- Red: Primary button ONLY
- Remove red from focus rings? (Keep for brand)
- All text: Black or gray (no colored text except errors)
- Icons: Gray (#737373)
```

### **Enhancement 5: REMOVE SUBTLE EFFECTS**
```
Current: Shadow-md on card
Swiss: More subtle or none

Options:
